# 27 sources for competitive intelligence

A visual take-home reference from Eric Do Couto for Product Marketing Summit SF 2026.

Open [the HTML reference](27-source-reference.html) or [the printable PDF](27-source-reference.pdf). The PDF has an index and one page per source.

Each of the 27 entries includes a PMM question, a proposed “Alert me when” condition, an ignore example, a suggested owner, and an interpretation note. Proposed conditions are examples and require testing on the selected page.

## Evidence labels

- **Source example:** a public page captured on 4 September 2026.
- **Source excerpt:** text from a linked public page or file, captured on 4 September 2026.
- **Historical Visualping capture:** an authentic dated image. Fluxguard pricing was captured on 6 January 2026; Airtable messaging was captured on 7 August 2026. The dates appear beside the images.

Current captures illustrate source selection. They do not establish historical changes. Screenshots retain their original pixels; HTML and PDF viewports select the relevant region.

## Files

- `27-source-reference.html`: portable HTML with embedded styles, relative image links, and public source links.
- `27-source-reference.pdf`: 28-page landscape Letter PDF with source links and an index.
- `source-manifest.json`: public source URLs, capture labels, image paths, and viewport coordinates.
- `assets/`: the 22 original images referenced by the HTML.

Keep the `assets` folder beside the HTML file. The HTML uses no scripts, remote fonts, analytics, or external image dependencies. The PDF is self-contained.

The technology-stack example uses public CMS generator metadata from the GitHub Blog feed. XML, robots.txt, feed metadata, RSS, and a financial-filing passage appear as source excerpts.

Source pages can change after capture. Company names, trademarks, and page content belong to their respective owners.
